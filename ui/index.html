Sync all Passwords

Use this to make all discovered units use one admin password.
1) Pick Sync to Primary or Sync to Fallback.
2) Click Sync to update units that are not already on that password.
Note: the password you are moving away from must be the unit's current password (or the sync cannot authenticate that unit).
To change the Primary/Fallback password values, open the ⚙ Configuration panel (gear icon) and update them there.

Set NTP

Set NTP server and timezone for selected units or all discovered units.
Units must be rebooted for NTP and timezone changes to take effect.
