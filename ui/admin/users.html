Display groups

A group is a set of displays that receive the same source. Routing to a group sends the source to each display in turn and checks each one; a display that does not respond does not stop the others. A group is not a Multiview — every display shows the whole picture.

Device names

Give a device a name people will recognise — Teacher PC, Front Display. Users see this name instead of the device's hostname. The device itself is not renamed and nothing is written to it; this is OmniSuite's own label. Clear a name to go back to the hostname.
